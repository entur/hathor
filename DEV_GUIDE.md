# Hathor Developer Guide

Hathor is a fork of **[Inanna](https://github.com/entur/inanna)** — Entur's React 19 + Vite + MUI v7 data-registry starter.

Adding an entity follows hathor's collection + form pages (`CLAUDE.md`, *Collection + form
pages*; ADR in `FORK_DECISIONS.md`, 2026-11-11). Modelling new NeTEx domains follows the global
**`inanna-fork`** skill in *extend mode*; its Generic Data View steps no longer apply here.

- **`OPEN_QUESTIONS.md`** — unresolved design ambiguities; companion to `FORK_DECISIONS.md`.
